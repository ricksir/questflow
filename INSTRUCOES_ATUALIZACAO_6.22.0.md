# Atualização QuestFlow Studio 6.22.0 + Mobile 0.15.0

## Studio

1. Feche o QuestFlow Studio, o Manager e qualquer janela Expo/Metro.
2. Extraia `QuestFlow_Studio_6.22.0_UPDATE.zip` em uma pasta temporária.
3. Execute `ATUALIZAR_QUESTFLOW_SEGURO.bat` como usuário normal.
4. Confirme a atualização partindo de 6.21.0 ou 6.21.1.
5. Aguarde a validação, o backup e a restauração segura.
6. Abra o Studio e confirme `Versão 6.22.0` no menu lateral.

## Mobile Android

1. Copie `QuestFlow_Mobile_0.15.0.apk` para o celular.
2. Abra o APK e permita a instalação desta fonte, se o Android solicitar.
3. Instale sobre a versão anterior para preservar o pareamento e a fila offline.
4. Abra o aplicativo e confirme `0.15.0` em Perfil.
5. Se o Studio não for encontrado, use Pareamento no Studio e leia um novo QR.

Não desinstale o Mobile antes de instalar o APK novo; a desinstalação pode remover dados locais ainda não sincronizados.
