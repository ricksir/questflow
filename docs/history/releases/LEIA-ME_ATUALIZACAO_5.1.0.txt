QUESTFLOW STUDIO 5.1.0 — PACOTE COMPLETO OTIMIZADO

INSTALAÇÃO RECOMENDADA
1. Feche qualquer instância do QuestFlow Studio.
2. Faça uma cópia de segurança da pasta data da instalação que você utiliza atualmente.
3. Extraia este ZIP em uma pasta própria.
4. Para continuar usando sua base atual, copie para esta versão os arquivos da sua pasta data, especialmente:
   - questflow_questions.sqlite
   - config.json, quando existir
   - question_images
   - markdown_cache
   - google_browser_profile, quando existir
5. Execute INSTALAR_E_DIAGNOSTICAR.bat uma vez.
6. Depois, abra pelo INICIAR_QUESTFLOW_STUDIO.bat.
