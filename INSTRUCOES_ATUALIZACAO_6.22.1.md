# Atualização QuestFlow Studio 6.22.1 + Mobile 0.15.1

## Studio

1. Feche o Studio, o Manager e qualquer janela Expo/Metro.
2. Extraia `QuestFlow_Studio_6.22.1_UPDATE.zip` em uma pasta temporária.
3. Dentro da pasta `QuestFlow`, execute `ATUALIZAR_QUESTFLOW_SEGURO.bat`.
4. Aguarde o backup, a validação e a restauração dos dados.
5. Abra o Studio e confirme `Versão 6.22.1` no menu lateral.

## Mobile Android

1. Copie `QuestFlow_Mobile_0.15.1.apk` para o celular.
2. Instale sobre a versão anterior; não desinstale o aplicativo.
3. Confirme `0.15.1` em Perfil.
4. Refaça o pareamento apenas se o Studio não for encontrado.

O pacote não altera nem recria o banco. O histórico passa a ser lido integralmente da tabela de respostas já existente.
